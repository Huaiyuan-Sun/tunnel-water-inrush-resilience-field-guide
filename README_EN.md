# Field Implementation Guide for Tunnel Water-Inrush Resilience Assessment

This repository converts the method presented in *Intelligent resilience assessment of water inrush in tunnel construction based on mixture of experts-LLMs system* into an auditable field procedure.

The Chinese guide is the normative operational version. It provides:

- a safety-gated field workflow;
- evidence and missing-data registers;
- recovery-time and vulnerability assessment forms;
- confidence-index weighting and a reproducible two-dimensional cloud-model calculator;
- action, approval, reassessment, and closure records;
- an anonymized worked example.

Start with [the Chinese README](README.md) and [`docs/quick-start.md`](docs/quick-start.md).

> This repository supports engineering decisions. It does not replace emergency plans, evacuation and rescue commands, statutory reporting, monitoring, design review, or licensed professional judgment.
