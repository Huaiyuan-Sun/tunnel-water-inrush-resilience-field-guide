# 贡献指南

欢迎通过 Issue 或 Pull Request 提交：

- 现场表单可用性改进；
- 新的匿名化工程案例；
- 知识图谱查询模板；
- 计算器缺陷和测试用例；
- 与现行法规、标准或项目制度的适配建议。

提交案例时必须删除项目名称、精确坐标、人员身份、联系方式、商业合同数据及其他敏感信息。不得提交未获授权的事故报告、照片或监测数据。

涉及计算规则的修改，应同时：

1. 说明修改依据；
2. 更新相应文档；
3. 增加或修改自动化测试；
4. 标明是否改变既有结果；
5. 更新 `CHANGELOG.md`。

安全相关变更不得仅凭语言模型输出合并，应由具备隧道工程、应急管理或相关专业能力的人员复核。

所有面向现场人员的新增或修改文档必须保持“完整中文在前、对应英文在后”的结构。两种语言应表达相同的规则、阈值、警告和责任，不得只翻译标题或省略安全限制。

# Contributing

Issues and pull requests are welcome for field-form usability, anonymized cases, graph-query templates, calculator defects and tests, and adaptation to current standards or project procedures.

Remove project names, precise coordinates, personal identities, contact details, commercial contract data, and other sensitive information. Do not submit unauthorized reports, photographs, or monitoring records.

A calculation-rule change must:

1. state its basis;
2. update the relevant documentation;
3. add or update automated tests;
4. identify whether prior results change;
5. update `CHANGELOG.md`.

Safety-related changes require review by a person competent in tunnel engineering, emergency management, or the relevant specialty. Do not merge them solely on the basis of an LLM output.

Every human-facing document must contain a complete Chinese section first and the corresponding English section below. Both sections must preserve the same rules, thresholds, warnings, and responsibilities.
